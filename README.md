# Veille thé — Liberthé

Résumé quotidien de l'actualité du thé (concurrents, nouveautés, études santé), lu par l'onglet « Veille » de l'appli Liberthé CRM.

- `veille/index.json` : liste des numéros, du plus récent au plus ancien.
- `veille/AAAA-MM-JJ.json` : un numéro (`day`, `title`, `body`, `sources`).

Aucune donnée client ni chiffre de vente dans ce dépôt.
